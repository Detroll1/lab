# LAB — витрина интерактивных визуальных экспериментов

Одностраничный портфолио-проект: **7 живых canvas/WebGL/GLSL-экспериментов** на чистом HTML/CSS/JS, без единой зависимости.

## Что внутри

| Эксперимент | Тип | Идея |
|---|---|---|
| **Поток** | Canvas 2D | Сотни частиц плывут вдоль curl-поля многослойного шума |
| **Ткань** | Canvas 2D + физика | Классическая cloth-симуляция на интеграторе Верле: гравитация, ветер, обрыв нитей; тяните мышью, двойной клик — новая ткань |
| **Стая** | Canvas 2D | Три правила Крейга Рейнольдса — сепарация, выравнивание, сцепление |
| **Аттрактор** | Canvas 2D | Орбита странного аттрактора (отображение де Йонга), 8 хаотических пресетов |
| **Тор 3D** | WebGL | Собственный WebGL-пайплайн: тор из ~9 тыс. треугольников с освещением Блинна–Фонга, drag/зум |
| **Плазма** | GLSL (шейдер) | Фрактальный шум в пять октав на GPU + палитры Ины Куинеке |
| **Глитч** | GLSL (шейдер) | Синтвейв-сцена нарисована в шейдере + RGB-сдвиг, срезы, блоки |

## Возможности
- Карточки с живыми превью (IntersectionObserver — запуск только видимого).
- Полноэкранный просмотрщик: `Esc` / крестик / стрелки ←→, deep-link `#exp-<id>`.
- Тёплый старт сцен (warmup) — картина видна сразу, до первого кадра.
- Адаптив 360px → 4K, доступность с клавиатуры.
- Открывается из `index.html` без сборки — можно запустить даже с `file://` (скрипты лежат в `js/`).

## Технические детали
- Структура: легковесная база в `js/util.js` (`Base2D`, `BaseWebGL`, `LAB.registry`), эксперименты — в `js/experiments/*.js`, каждый регистрирует себя в `registry`.
- Синтаксис всех JS проверяется GitHub Actions (`node --check`) при каждом push.
